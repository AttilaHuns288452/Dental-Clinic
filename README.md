# Dental Clinic

Full-stack dental clinic app — React frontend + Express backend in one repo.

## Structure

```
Dental-Clinic/
├── frontend/          React + Tailwind + Vite
│   ├── src/
│   ├── package.json
│   └── vite.config.js
├── backend/           Express API
│   ├── src/server.js
│   └── package.json
└── .gitignore
```

## Quick Start

```bash
# Frontend (terminal 1)
cd frontend && npm install && npm run dev     # localhost:5173

# Backend (terminal 2)
cd backend && npm install && npm run dev      # localhost:3000
```
